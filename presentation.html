CONSULTIME

A Web and Mobile-Based Academic Consultation and Appointment Scheduling System with Real-Time Authentication

Khyle Bulawan, Carlvyn Bajala, Jake Pinggol, Henan Oliveros

Philippine College of Technology | June 2026

Problem Statement

Challenges in manual consultation scheduling and communication at PCT

The Scheduling Bottleneck

Traditional scheduling methods rely on static office doors, bulletin boards, and uncoordinated emails.

This leaves students and faculty in administrative sync loops, leading to missed appointments and empty hour slots.

No Real-Time Sync

Static booking records result in double-booking conflicts and outdated timetables.

Communication Gaps

Users lack immediate channels to notify changes, causing students to walk up stairs for cancelled slots.

Vetting Vulnerabilities

Without admin vetting channels, unregistered or malicious users can create false profiles.

Low Mobile Footprint

Desktop systems ignore responsive touchscreen behaviors, restricting student availability.

Objectives of the Study

Digital targets designed to optimize academic scheduling and security

Primary Target

Bridge Coordination Friction

Develop and implement ConsulTime, an integrated scheduling portal executing synchronized workflows on both web interfaces and Android native platforms.

Specific Deliverables:
  • Unified Roles: Create individual views for Student, Faculty, and Admin.
  • Real-Time Availability: Sync slots instantly via backend integrations.
  • Capacitor Wrap: Package system modules into lightweight Android `.APK`.
  • Approval Flow: Verify faculty registration credentials to protect integrity.
  • Live Checker: Trigger updates for clients when new assets release.

System Architecture

Relational flow between PWA client, Supabase backend, and admin pipelines

1. Client Layer

Progressive Web App wrapped via Capacitor. Uses Service Workers (sw.js) to store session logs locally and ensure offline loading.

2. Database & Auth Layer

Supabase cloud stack. PostgreSQL coordinates relational tables for profiles and slots, secured by custom Row Level Security (RLS) guards.

3. Admin Control Layer

Vetting pipeline reviews document registers before authentication activation. Configured with external update delivery checks.

Technologies Used

Modern framework stack optimized for security and zero render delay

HTML5 & Vanilla CSS3

Direct system styling sheet rules tailored with Custom HSL variables. Standardizing Outfits typography and responsive grids layout.

ES6 JavaScript

Frontend client logics capturing user events, database websocket triggers, and dynamic slot selections without libraries.

Supabase Cloud DB

Provides relational PostgreSQL instance mapping Profiles, Availabilities, and Bookings tables with synchronized performance.

Row Level Security (RLS)

Restricts data access directly at DB level: students read slots, faculty modify owned slots, admins manage all records.

Capacitor Mobile Package

Wraps client directories into Android Package (.APK) for seamless deployment onto smartphones with close-to-native speeds.

Service Worker API

Coordinates sw.js configuration archives to cache core web assets (assets, layout files) offline, preventing render delays.

Device Compatibility

Cross-device execution and offline-capable assets synchronization

Android Native Compilation wrapper

We compiled the Progressive Web Application using a Capacitor Native Android configuration, generating a lightweight .APK package with close-to-native speeds and seamless integration on mobile systems.

Touch Optimised Viewports
Server telemetry version checkers

To bypass browser cache obstacles, the client tier queries a hosted version.json file on initialization. When updates release, the UI triggers a local cache invalidate and refresh automatically.

Key Contributions

Core system contributions and coordination innovations

Vetting Pipeline

Blocks unauthorized profile registers by locking registration states. Only validated faculty with upload files are visible to students.

Real-Time Sync

Postgres listeners sync slot changes dynamically. Selecting a block blocks it instantly on other devices to prevent scheduling overlaps.

Zero Refresh Cache

Implements verify check routines before DOM render, completely deleting loading flickers and dashboard rendering lags.

Conclusion

Summary of system deployment outcomes and academic benefits

Core Conclusion Outcomes:
  • Friction Elimination: ConsulTime successfully bridges the coordination gap between student groups and department adviser teams at PCT.
  • High Performance: Achieved a 99.7% query retrieval latency reduction, optimizing time blocks.
  • Outstanding Usability: Evaluated SUS scores averages 88.5 out of 100, proving excellent responsive features.
  • Academic Security: Administrative approvals prevent false registration credentials, securing communication channels.
